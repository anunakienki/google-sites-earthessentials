Garden of Balance — video file guide
=====================================

Upload your HeyGen exports here, one subfolder per guide, using these exact
filenames (matching what's referenced in earthyessentials/index.html):

videos/gaia/what-is-the-garden.mp4
videos/gaia/which-guide.mp4
videos/gaia/first-timer.mp4

videos/indica/what-is-indica.mp4
videos/indica/sleep.mp4
videos/indica/best-time.mp4

videos/sativa/what-is-sativa.mp4
videos/sativa/focus.mp4
videos/sativa/best-time.mp4

videos/hybrid/what-is-hybrid.mp4
videos/hybrid/leaning.mp4
videos/hybrid/first-time.mp4

To add, remove, or reword a question — or add a new guide entirely — edit the
GUIDES object near the bottom of earthyessentials/index.html. Each entry is:

  { q: 'The question text shown as a button', file: '/videos/guide/name.mp4' }

Just make sure the file path you type there matches the filename you actually
upload. Delete this README before going fully live if you'd rather it not
be public (it's harmless either way — it's just a text file).

A note on file size: keep clips reasonably compressed (H.264 MP4, 720p is
usually plenty for talking-head answers) — GitHub works best with individual
files under ~50-100MB, and smaller files load faster for customers on mobile.
